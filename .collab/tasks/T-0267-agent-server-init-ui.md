# T-0267 智能体服务器：按效果图优化服务器详情页头与“连接与初始化”区块（含初始化进度）

## 目标
人类 2026-11-16 在对话里给了智能体服务器详情页“初始化失败”时的截图，说初始化过程中样式太混乱；
claude 先出了效果图（失败整页 + 进行中 / 已完成 / 未初始化 / 展开命令输出四种状态），人类确认“按这个效果图开始做”。
只改服务器详情的页头和“连接与初始化”区块的布局与样式，以及部署 / 卸载共用的 SSH 任务进度组件；接口、权限、后端不变。

## 验收标准
- [x] 页头：名称 + 状态，下面一行五格（连接、服务器环境、CPU、内存、部署智能体）；没有上报时写“暂无上报”，不画 0 的进度条
- [x] “连接与初始化”：标题右边只有一个主按钮（初始化服务器 / 重新初始化）；左边是最近一次任务，右边是“登录前提”检查清单（地址、密码、指纹、连接测试，各自的操作放在旁边），底部单独一行“移除服务器”并写清后果或不能移除的原因
- [x] SSH 任务进度（初始化 / 部署 / 卸载共用）：标题 + 状态 + 开始时间与用时；按步骤分格的进度条；带图标的步骤时间线，说明降为副行；失败原因挂在失败那一步下面；任务结束后没跑的步骤显示“未执行”；进行中那一步下面显示最新几行输出；命令输出默认折叠、展开后带行号、命令行和报错行分色、可复制；成功后收起成一条成功条，可展开每一步
- [x] 主机指纹待核对、待补充密码、旧公钥退役等原有流程照常可用，不丢功能
- [x] 亮色、暗色、手机宽度（390px）都正常，没有横向滚动
- [x] 前端 lint / typecheck / test / build / check:api 通过；浏览器里截图对照效果图；CI 的智能体服务器浏览器验收通过

## 背景 / 约束 / 参考
- 不改后端与接口：步骤、失败原因、错误码、命令输出都取自现有的任务记录（`AgentSshJobOut`）。
- `tests/e2e/agent_ssh_browser.cjs` 依赖进度区块的文字结构，跟着改（它在 T-0224 的 paths 里，codex 已暂停，D-0007）。
- 容器服务器的 SSH 部署（`features/runner/RunnerSshDeploy.vue`）有自己的进度列表，本任务不改。
- 与效果图的差别：失败原因框里只放“查看命令输出”，不再放第二个“重新初始化”（标题右边已有主按钮，同一区块两个同名按钮会混淆）；
  登录前提每项的时间单独一行（和状态写在同一行时，窄栏里会把“连接正常”拆成两行）。
