# T-0232 大模型聚合聊天页面（二）：多模型同问——同一个问题同时发给几个模型，并排看回答

## 目标
“大模型聚合聊天页面”的第二步（人类 2026-11-13 确认的效果图 2，方案 `docs/v2/LLM_CHAT_PLAN.md` 第 3.4、4.3 节）：
同一个问题同时发给几个“管理器 + 平台 + 模型”，并排看回答。接 T-0231（单会话聊天）。

## 验收标准
- [x] 左栏“多模型同问”进入新建：默认把当前管理器上已登录、能对话的平台加进来；可以添加别的管理器上的模型（2 ~ 6 个，可以跨管理器）
- [x] 同一个问题同时发出：每个模型各开一个普通会话；某个目标建不成（没登录、限额）只影响它自己那一栏，原因写明；一个都没建成时不留下空的一组
- [x] 一组并排显示：每栏有平台、模型、管理器、状态和回答；“停止这一个”“在这个会话里继续”（回到单会话）“复制回答”
- [x] 向一组继续发；重试不会重复（幂等号）；别人建的一组要确认一次（接口不带 `takeover=true` 返回 `409 TAKEOVER_REQUIRED`）
- [x] 管理器停用或登记被删除后，那一栏给出原因，其余照常
- [x] 归档一组只是不再并排显示，每个模型的会话不受影响
- [x] 左栏最上面的“同问”列出各组；地址里带着分组（`?g=`），刷新后还在
- [x] 权限：owner / admin 可用，member 403；审计记动作，不记问题的内容
- [x] 手机宽度下一次看一栏，不横向滚动
- [x] 分组登记在工作台：两张表和迁移 `0069`（可升可降，与模型一致）；消息内容仍然只在会话桥里
- [x] 后端、前端的测试；浏览器验收脚本加上同问的步骤，本机跑通
- [x] CI 全部通过后才合并（D-0004）——这一项随合并成立

## 背景 / 约束 / 参考
- 每个成员就是会话桥上的一个普通会话：建会话和发送照常走会话桥的工具（密钥拦截、限额、账号一致性、排队都一样）。
- 没有改 `docs/AGENTS.md`：这里是人在操作，不涉及例外九。
