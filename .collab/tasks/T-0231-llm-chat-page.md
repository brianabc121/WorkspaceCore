# T-0231 大模型聚合聊天页面（一）：单会话聊天——浏览全部会话、新建、问答、停止、改标题、归档

## 目标
人类 2026-11-13 要求：给“大模型客户端管理”加一个查看页面，像各家的客户端一样浏览每个大模型的全部会话、向大模型提问；
先出效果图（已确认），再按方案写开发文档并全面落实。方案见 `docs/v2/LLM_CHAT_PLAN.md`。

本任务是第一步：单会话聊天。第二步“多模型同问”是 T-0232。

人类确认的三件事（效果图说明里我的建议，人类回复“可以”）：
1. 聊天页只给 owner / admin 用；
2. 智能体建的会话可以看，接着发消息前要确认一次（后端同样要求）；
3. 分两步做：先单会话聊天（本任务），再多模型同问（T-0232）。

## 验收标准
- [x] 开发文档 `docs/v2/LLM_CHAT_PLAN.md`：页面、做法、权限与安全、测试、任务拆分、不做的
- [x] 入口不变（侧栏“大模型客户端”，`/llm_bridge`）：默认是聊天，原来的管理页面在“管理器与账号”（`/llm_bridge?view=manage`）
- [x] 左栏：选 MCP 管理器、新建会话、按标题搜索、按平台筛选（没登录的标出来）、按“今天 / 昨天 / 更早”分组、
      每行写明平台、用法、谁建的；可以看已归档的；可以同步官方程序里的会话
- [x] 对话：我发的在右、回答在左；回答按纯文字显示，三个反引号里的排成代码块，不渲染 HTML；
      回答一段一段出现；开发会话的“过程”可以展开；失败、结果未知、已停止如实显示
- [x] Enter 发送、Shift + Enter 换行；回答中可以停止；上一条没答完时下一条排队；结果未知时重发不会发两次（幂等号）
- [x] 改标题、归档；归档后不能再发
- [x] 新建会话：管理器 → 平台（只列它控制的，没登录的不能选）→ 用法 → 模型、推理强度 → 开发环境（开发会话必选）→ 第一条消息
- [x] 接着别人或智能体建的会话发消息：页面确认一次；接口不带 `takeover=true` 返回 `409 TAKEOVER_REQUIRED`；记审计
- [x] 权限：owner / admin 可用，member 403 且看不到入口；管理器停用后只能看（`409 BRIDGE_DISABLED`）；模块停用时 404
- [x] 审计记动作（新建、发送、接手、停止、改标题、归档），不记消息内容
- [x] 手机宽度：列表和对话分成两屏，不横向滚动
- [x] 会话桥、工作台后端、前端的测试；浏览器验收脚本 `tests/e2e/llm_chat_browser.cjs`，本机跑通
- [ ] CI 全部通过（含 `ci-llm-bridge` 的 `workspace` job 里新增的聊天验收）

## 背景 / 约束 / 参考
- 人以 `user:<用户 id>` 的身份经 MCP 管理器发消息，和智能体走的是同一套工具：密钥拦截、限额、账号一致性、排队都一样。
- 浏览器不直连 MCP 管理器，也拿不到管理令牌；读走管理接口，写走工具。
- 没有改 `docs/AGENTS.md`：这里是人在操作，不涉及例外九。
- 需要真实账号的验收（各平台的真实回答）不在本任务范围。
