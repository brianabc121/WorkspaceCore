# T-0085 UI 优化第 3 批：首页（问候、更多菜单、重试按钮、今日任务链接）与日历月视图

## 目标
人类要求（2026-11-02 / 11-03）：「给我重新优化一下整个工作台的 UI 以及功能」「继续做第 3 批」。第 3 批：首页与日历。
审查发现：首页工具栏 7 个按钮常驻；任务组件在正常时也显示“重试组件”；今日任务不能点；日历只有日程列表和周视图。

## 验收标准
- [x] 首页标题下显示问候语和今天的日期（按浏览器时间）
- [x] 首页工具栏：刷新（图标）、添加组件、编辑布局常驻；导出 / 导入 JSON、选择仪表盘、设为首页收进“更多”菜单（viewer 只有导出与选择）
- [x] 任务组件只在出错或数据过期时显示“重试组件”
- [x] 今日任务可以点开任务抽屉，显示项目与截止时间（逾期标红）；任务组件有“查看任务”链接
- [x] 日历月视图：6 周网格（周一开始），显示日程与任务截止，标出今天和不在当月的日子；上个月 / 下个月；点日期切到那一周；手机上显示圆点
- [x] 前端 lint / typecheck / test / build / check:api 通过；浏览器截图验收；受影响的 e2e 脚本同步更新

## 背景 / 约束 / 参考
- 只改前端，接口不变：月视图读取范围 6 周 + 两天时区余量（46 天），在日历接口 92 天上限内。
- 依赖 T-0083、T-0084 的外框、设计令牌与任务页工具。
