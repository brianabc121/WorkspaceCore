# T-0083 UI 优化第 1 批：视觉基础（设计令牌、图标）、精简顶栏与侧栏、紧凑页头、中文日期与本地时区

## 目标
人类要求（2026-11-02）：「给我重新优化一下整个工作台的 UI 以及功能」。按页面截图评审的结论分批做，本任务是第 1 批（外壳与视觉基础）：
- 顶栏 9 个文字按钮挤在一起，手机上折成 3 行；侧栏 15 项只有占位圆点；页头占约 200px；
- 日期是美式格式带秒（`11/2/2026, 12:28:44 AM`），日历默认 UTC 时区。

## 验收标准
- [x] 设计令牌：颜色（亮 / 暗）、状态色、圆角、侧栏与顶栏尺寸整理成一套，外框统一使用（页面内容在后续批次逐步换用）
- [x] 图标：侧栏每项有图标；顶栏的搜索、创建、消息、待审批、通知、AI 助手和主题改为图标按钮（无障碍名称不变）
- [x] 账户菜单：显示名、邮箱、个人设置、安全设置、登出（当前工作空间放在侧栏顶部）；手机上顶栏只占一行
- [x] 侧栏分组可以折叠（记住状态），管理分组默认收起；打开某页时展开它所在的分组
- [x] 页头紧凑：去掉重复的工作空间名，标题与说明更小
- [x] 日期统一用中文格式、不显示秒；日历默认浏览器本地时区（已是如此，审查时的 UTC 来自无头浏览器的时区）
- [x] 前端 lint / typecheck / test / build / check:api 通过；浏览器截图验收（亮 / 暗 / 手机）；e2e 脚本里受影响的操作同步更新

## 背景 / 约束 / 参考
- 后续批次：第 2 批任务与项目（勾选完成、快速新建、智能视图、看板拖动、项目颜色与进度），第 3 批首页与日历（月视图），第 4 批手机与无障碍。
- 只改前端，不改接口。
