# T-0261 大模型客户端：按效果图优化聊天页的界面样式（V2）

## 目标
人类 2026-11-16 在对话里给了一张效果图，要求按它优化“大模型客户端”聊天页的界面样式。只改样式和布局，功能、接口、权限不变。

## 验收标准
- [x] 页头：图标、标题“大模型客户端”、一句说明，右侧四个视图标签（对话 / 会话记录 / 会话纪要 / 管理器与账号）
- [x] 三栏分成三张卡片：左栏（管理器与连接状态、新建会话、搜索、平台筛选、按天分组的会话、底部“同步官方会话”“已归档”）、中间对话、右栏会话详情
- [x] 对话头部：标题 + 平台 / 模型 / 用法 / 开发环境的标签；操作按钮收拢成一排图标
- [x] 消息：头像、提问气泡靠右、回答卡片、过程折叠条（状态 + 步数）、回答下面的操作按钮带图标；清空 / 压缩的分隔线
- [x] 输入框：一个圆角框，下面一排工具（附件、知识库、开发环境、Enter 发送、发送）
- [x] 右栏：会话详情，概览 / 执行记录两个标签；运行配置、用量概览、会话纪要、执行记录几张卡片
- [x] 亮色 / 暗色都只用主题变量；手机宽度可用
- [x] 前端 lint / typecheck / test / build / check:api 通过；浏览器里截图对照效果图

## 背景 / 约束 / 参考
- 效果图里的回答内容（“本次会话用量 90k tokens”等）是示例数据，不是要做的功能；全局主题色不改（沿用 `--accent`）。
- 测试依赖的无障碍名称尽量不变；必须改的同步改 `apps/web/tests/llm_chat.test.ts` 与 `tests/e2e/llm_chat_browser.cjs`。
