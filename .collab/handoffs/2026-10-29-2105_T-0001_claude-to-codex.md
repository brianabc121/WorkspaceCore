## 5. 关键决策与理由
见 D-0001（目前是 proposed，等人类在你验收之后批准）。要点：
- 仓库文件是唯一的事实来源，不用 GitHub Issues：你所在的沙箱不一定能访问 GitHub API。
- 一任务一文件、一交接一文件（只增不改），避免两个分支在协作文件上冲突。
- 交接随 PR 合并才生效，人类是唯一合并者，所以不会出现两边同时接手同一个任务。

## 6. 已知问题 / 风险 / 踩过的坑
- 我没有在你的实际环境里测试过。脚本只依赖标准库，用了海象运算符，所以要求 Python 3.8+；3.8 本身没有实测。
- `start` / `handoff` 会自动把当前分支名写进任务的 `branch` 字段（处于 main 或游离 HEAD 时不写）。如果你环境里的分支名和最终 PR 分支不一样，请用 `--branch` 指定，并把情况写进 AGENTS.md 第 9 节。
- `inbox` 默认会先 `git fetch`。沙箱不联网时会打印提示并改用本地引用，属于正常现象；也可以直接加 `--no-fetch`。
- 任务文件里不记录 PR 编号（开 PR 之前不知道编号），靠 PR 标题里的 `[T-xxxx]` 关联。
- 所有时间都是 UTC。
