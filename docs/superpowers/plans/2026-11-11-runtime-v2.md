# Runtime V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落实双服务器池默认自动/可指定部署、5个保有容器及独立审批、同实例跨节点私网和严格入口。

**Architecture:** Workspace负责授权、指标筛选、负载排序和原子预约；OpenClaw沿用受控Docker部署。legacy Docker环境保持原后端，新运行环境通过受限Kubernetes适配器及Cilium策略执行；默认拒绝跨实例访问，跨实例/公网使用带身份的网关。

**Tech Stack:** Python 3.12 / FastAPI / Pydantic 2 / SQLAlchemy / PostgreSQL，Vue 3 / TypeScript / Node 22，Kubernetes REST API与Cilium。

**Spec:** `docs/superpowers/specs/2026-11-11-runtime-v2-design.md`

## Global Constraints

- 默认5个保有容器，停止/未知/待删除计入；数量豁免不放宽CPU/内存/磁盘。
- auto默认；specified是硬约束，不静默换机；旧server_id请求保持specified语义。
- workspace与实例权限服务端校验；不开放hostNetwork/privileged/Docker socket。
- 实时负载、新鲜度、创建预约同时参与；unknown不按TTL释放或重复创建。
- 本次人类“根据方案全面落实代码”授权本任务跨前后端与平台范围，不修改其他任务或未提交文件。
- 推荐目标入站同意作为安全默认实现；不修改协作协议、不开生产授权、不合并PR。
- schema.d.ts仅从正式OpenAPI生成；禁止手写生成文件。
- 不将单元测试或mock当成真实多节点验证；外部环境缺失明确报告。

## Review Focus

- 两个并发创建不能使用同一份容量：真实PostgreSQL锁与计数测试。
- 指标过期、未部署过智能体的空服务器：未知拒绝，受信独立探测后可候选。
- 指定、复用和本地卷恢复目标不符：明确冲突，不双建。
- 审批写入后异常回滚/登记人代替owner：持久申请、critical owner凭证、撤销可追踪。
- 共享exec与公网NAT回流绕过身份：跨实例只能复制，网关鉴别源身份而非共享IP。

**Files:** Create `app/schemas/placement.py`, `app/domain/placement.py`, `tests/test_placement.py` under services/api.
**Interfaces:** `Placement(mode='auto'|'specified',server_id: UUID|None)`; frozen `ResourceRequest(cpus,memory_mb,disk_gb,runtime=None)`; `Candidate(server_id,cpus,memory_mb,disk_gb,available_memory_mb,disk_free_gb,cpu_load,committed_cpus,committed_memory_mb,committed_disk_gb,observed_at,enabled=True,runtimes=())`; `rank_candidates(candidates,request,placement,now)` returns eligible sorted candidates, raises `PlacementError(code,message,reasons)` otherwise. Capacity has 10% headroom, freshness60s, non-finite/negative metrics reject. DB locks and effective reservations belong to pool adapters.
