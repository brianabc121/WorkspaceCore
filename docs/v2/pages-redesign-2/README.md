## 阅读顺序

1. [设计与产品规范](docs/superpowers/specs/2026-11-09-knowledge-news-dev-ops-design.md)：布局、真实能力、数据口径、权限及验收。

3. assets 中的四张页面图和一张首页风格参考。

核对基线为 `origin/main 5f5e9c88b652ad938cef3941be6957642f15bb47`，已包含首页 PR #177。Claude 开工必须重新 fetch 最新主干，确认相同任务、已合并功能和路径占用。
本包没有领取任务或预占编号，没有修改业务代码，没有执行产品测试、建 PR 或部署。`MANIFEST.json` 提供文件大小与 SHA-256，供核对文件完整性。

## 必须保留的业务边界

- **知识库：** 保留独立工作区、完整图谱、编辑／历史／回收站／README／AFFiNE入口；全量统计不能从图谱截断或第一页估算。归档不等于人类一律不可编辑。
- **早报：** 留在现有 news 模块；真实 Markdown 有几段就展示几段，来源必须可追溯。刷新只重新读取，不重新生成、推送或修改兴趣。
- **开发者：** GET只读本地GitHub投影。“待审PR”改成有证据的“开放PR”；不将最新仓库运行贴到任意PR。四项权限来自实际核验快照，缺失显示未核验。
- **运维：** 区分服务异常、未检查、未配置及采集故障；缺测不补0，P95不跨序列平均，Grafana故障不代表Prometheus故障。存储自检有探测写入，仅管理员显式触发。
- **通用：** 数字／记录／告警为图中示例；以接口和设计规范为准。权限撤销清缓存，局部失败保留合法数据，不新建第三方写权限或监控控制台。
