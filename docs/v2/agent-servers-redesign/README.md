## 五个必须落实的边界

- 取消的是**OpenClaw服务器SSH客户端密钥登录**；主机指纹、mTLS／实例令牌、工作台密钥库和Runner不删除。
- 密码加密、只写不读；所有OpenClaw SSH操作都要改，不仅隐藏密钥按钮。工作台账号二次认证密码仍与服务器密码分开。
- 旧服务器密码不能从私钥恢复，需补录；已有实例不停、不重装。旧公钥只能经密码登录后精确移除自己的那条，不清空authorized_keys。
- 复用现有一机多实例隔离，保留独立Compose项目／目录／网络；失败重试继续原instance_id，不能再创建一个实例。
- 效果图的“已停止”和容器名必须有真实证据。首期使用真实连接状态／部署进度，没有证据显示未知；默认资源仍不限制，图中2核／4GB不是新全局缺省。
