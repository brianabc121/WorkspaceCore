## 必须准确落实

- 改用户可见名称，保留/runner、现有API／MCP工具／模型命名；V1仍为每空间一台容器服务器。
- CPU实际用量不等于CPU配额，必须真实差分采集；首样本／重置／缺测显示未知，有效零增量才显示0。
- 内存限额按MiB，磁盘列按当前接口改为“数据卷占用”，不含镜像与可写层，不假装硬磁盘配额。
- 列表补服务端分页／搜索及匹配total，覆盖现有500条上限之外记录。每项指标分别显示上报时间；host poll在线不能掩盖report失效。默认60秒报告、30秒读页、180秒过期，图片10秒为示例。
- 原归属、模板、执行、服务器接入／SSH、权限、快照和生命周期功能保留。停止／归档／删除的数据影响分别说明；不把保护写成无条件永久保留。
- 本轮不重构Runner认证；与上一份智能体服务器密码改造分开，若路径重叠按协作协议串行。
