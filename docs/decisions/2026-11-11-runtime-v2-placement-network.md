## 授权与边界

本聊天“根据这份方案全面落实代码”授权前后端/平台跨模块实施所链接设计。现行AGENTS例外八“不得访问私有网段”在新受管容器域内作精确例外：同workspace同OpenClaw的受管工作负载可以跨节点通信。Workspace、智能体服务器、元数据和其他私有网络继续保护；不得扩大成任意私网访问。旧Docker环境不因本次更新进入新私网。协作协议和其他任务状态不改。

默认auto；用户可指定智能体服务器，用户/已开运行权限的OpenClaw可指定容器服务器。specified为硬约束，容量/权限/指标不可绕过；未知创建结果需对账，不自动换机双建。

本设计采用目标入站允许作为跨实例通信的安全默认。数量权限和通信权限独立，critical owner审批；不因为授权数量无限取消资源预算。数据库/控制器确认与节点实际策略应用分开记录。

## 实施取舍

- 共享纯Placement选择器；每池适配器在数据库事务下以实例与宿主锁建立持久预约。现有部署记录、环境和命令承担持久预约/实际位置事实，避免两份不一致账本。
- 智能体用独立受控SSH探测得到可信快照；实例上报不覆盖选址来源。新部署初值1CPU/2048MiB、10GiB调度磁盘预算，可通过配置调整。磁盘预约不宣称文件系统已强制限额；旧null上限不自动修改，不明资源不得算零。
- 新运行网络采用Kubernetes/Cilium的独立后端；无真实节点验证前不启用。原Docker执行器继续管理legacy数据和卷。指定节点仍通过原生调度容量校验。
- 停止保留容器名额与磁盘；仅确认停止后释放计算。重启在实际原宿主重新预约，旧上报不能取消新预约。

## 资源采样与并发补充

已有容器的“承诺上限减去当前可信工作集”仍占可用内存预约；只检查总承诺和 MemAvailable 会漏掉外部进程占用。Linux Docker stats 的 inactive_file（v1 为 total_inactive_file）不能当作不可回收工作集抵扣。SSH 采样通过固定 Docker CLI 格式读取 ID、Compose 身份和工作集显示值，并向下扣一档显示精度避免舍入多记信用；未匹配到受管部署的用量不能抵扣平台承诺。runner 直接读取统计字节数；缺失或非法值不补零。实时内存和总承诺都留 10% 总量余量。

runner 0.2.0 在采样前从认证接口领取绑定宿主的单次票据；平台起始时间才证明这次采样在资源预约之前还是之后。票据过期、重复或跨宿主使用返回 REPORT_SAMPLE_STALE。旧版本遥测仍可读，但不参与新增调度，也不解除新计算预约。暂停及未知运行状态继续保留计算。

锁顺序统一：实例 → 按 ID 排序的服务器池 → 环境；上报与结果回执先锁实际服务器，结果再锁命令和环境。真实 PostgreSQL NOWAIT 测试确认等待服务器时尚未持有环境锁，避免 host→env 与 env→host 相互等待。网络/SSH 调用不在这些行锁事务内执行。

MCP env_create 的成功对象与持久审批对象仍是联合类型，但 JSON Schema 顶层明确 type=object，以满足 SDK 的工具目录契约。服务器和节点显示名放入 untrusted，不将用户文字升级成指令。

## 物理身份、遥测缺失与磁盘余量（2026-11-12）

0065 使用标准化 Linux machine-id 的 SHA256 摘要作为全局物理登记主键，绑定唯一角色与服务器，并以组合外键约束 workspace。SSH 固定只读探测和 runner 固定只读宿主挂载产生相同摘要；原始标识不上传。登记使用 PostgreSQL 冲突仲裁，重复请求只有同一归属可幂等成功，不能覆盖另一登记。两种 SSH 安装器先占位再进行远程变更；容器服务器删除与 SSH 作业创建采用 host→target 锁顺序，运行中作业阻止删除释放身份。降级在账本排他锁内拒绝非空删除。克隆 machine-id 会被保守拒绝，需要人工核实，不扩大成信任任意客户端提交的 IP。

控制器命令的顶层 host_id 始终取实际宿主，覆盖调用者提供的值。允许未知资源心跳领取已有指令，但不伪造 Docker 版本/磁盘/CPU 数字：资源缺失时保留旧显示值、撤销采样新鲜度，直到新的完整可信报告恢复。心跳和报告在同一宿主锁下更新，防止新旧 JSON 快照覆盖。

磁盘没有可信逐环境使用字节时不提供抵扣：所有保有预算保守占当前空闲盘，另留总盘 10% 的紧急余量。此选择可能重复预留已使用字节而少分配，优先避免漏算未用承诺；未来增加可信用量归属再单独优化。Docker 磁盘字段仍是调度预算，不宣称强制文件系统配额或对外部进程的硬隔离。
