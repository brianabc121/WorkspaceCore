# 2026-11-03 消息页改为独立页面、聊天应用式布局（T-0095）

## 1. 背景

原来的 IM 页面套在工作台的侧栏与顶栏里，由“会话 / 通讯录 / 建群”三个按钮、表单式的会话列表和聊天框组成，
信息密度低，手机上也不像聊天应用。人类要求参照常见聊天应用（Telegram 一类）的样式重做，做成单独的页面，
分电脑端与移动端两套布局。先出效果图（https://claude.ai/artifact/FcmE8KD2Jhibqzt3rHT9Q4 ），人类确认后要求全面落实。

只借鉴这类应用通用的布局与交互（左侧会话列表、气泡、置顶消息条、右侧信息栏、侧滑菜单），
不使用任何产品的图标、名称、配色或聊天背景图。

## 2. 设计

### 2.1 独立页面

- 路由 `/im` 的 meta 加 `standalone: true`；`App.vue` 遇到独立页面只渲染 `RouterView`，不渲染侧栏、顶栏、底部导航与 AI 抽屉。
  工作台的实时事件（SSE）仍在 `App.vue` 里订阅，消息页照常自动刷新。
- 返回工作台、通讯录、新建群聊、夜间模式放在左上角的侧滑菜单里（shadcn-vue `Sheet`）。
- 权限不变：路由仍是 owner / admin 专用（member 打开 `/im` 跳到无权访问页），所有读写仍由后端按工作空间与角色校验。

### 2.2 布局与地址

| 宽度 | 布局 |
|---|---|
| ≥ 1280px | 三栏：会话列表（360px）/ 聊天 / 会话信息（340px，可收起） |
| 768–1279px | 两栏；会话信息盖在聊天右侧 |
| < 768px | 一次一栏：会话列表 → 聊天 → 会话信息；亮色主题下顶栏用主色 |

地址参数决定显示什么，刷新、后退都回到同一处：`c=<会话>`、`view=contacts`（左栏显示通讯录）、`info=1`（打开会话信息）。
手机上进入下一层用 `router.push`（系统返回键回到上一层），宽屏用 `replace`。CSS 按根元素的 `data-pane` 切换手机上显示哪一栏。

### 2.3 组件

`features/im/`：`ImWorkspace`（状态与三栏）、`ConversationList`（菜单、搜索、分类、列表、右下角“新建”）、`ContactsPanel`（通讯录与分组管理）、
`ChatWindow`（顶栏、置顶消息条、按日期分隔的气泡、输入区）、`MessageItem`（气泡）、`ChatInfo` + `GroupDetails`（会话信息、群公告、成员、防刷屏、解散）、
`ImMenu`（侧滑菜单）、`ChatAvatar`（头像）、`usePopover`（小弹出菜单）、`format.ts`（时间与颜色）、`im.css`（样式）。
原有的发送逻辑全部保留：每个草稿一个幂等键（结果未知时重试不会发两次）、发送中的消息与服务端“sending”行去重、已读只标一次、图片先校验类型与大小、外部图片不自动加载。

### 2.4 交互上的变化

- 分类：全部 / 单聊 / 群聊 / 通知，加上每个通讯录分组。数字是“有未读的会话数”（只有开了免打扰的会话有未读时用灰色）；
  接口只给全部会话的未读消息总数，所以分类的数字由已加载的会话算出，会话没有全部加载完时不显示，避免显示错的数字。
- 搜索边输入边筛选（停顿 300 毫秒）；手机上点搜索图标展开。
- 输入框：电脑上 Enter 发送、Shift + Enter 换行；手机上 Enter 换行；Ctrl / ⌘ + Enter 都发送；输入法选字时的 Enter 不发送。
- @ 成员改为弹出的成员列表（只列出其他成员）；选中的成员显示在输入框上方，可以去掉。
- 置顶消息条一次显示一条，点一下跳到那条消息并换到下一条；条上可以取消置顶。单条消息的置顶 / 取消置顶在气泡旁的“消息操作”菜单里。
- 发送失败（确定没有发出）的文字消息可以“重新发送”，作为一条新消息、用新的幂等键；结果未知的消息不提供重发（可能已经发出）。
- 导出聊天记录在顶栏“更多”菜单和会话信息栏里；置顶会话、免打扰在顶栏（手机上收进“更多”）和会话信息栏里。
- 已解散的群与通知会话不显示输入框。工作台通知账号（`ws_notice`）在群里显示为“工作台通知”。
- 会话列表里不显示“有人 @ 我”：会话接口没有这个字段，消息里仍然标“@ 了我”。

### 2.5 颜色

消息页用自己的一组颜色变量（`--im-*`，亮 / 暗两套，跟随工作台的主题开关），放在 `:root` 上，挂到 body 上的侧滑菜单也能用。
文字与背景的对比度都不低于 4.5:1（例如主色 `#1a6fd1` 上的白字 4.95:1；浅蓝底上的文字用更深的 `#155db0`）；
未读数在免打扰时改用浅灰底深色字，与普通未读在明暗上也能区分。头像与发言人名字的颜色按名字固定（FNV-1a 取 6 色之一）。

## 3. 验证

- `apps/web`：`npm run lint`、`npm run typecheck`、`npm test`（IM 测试 26 个，新增独立页面、分类与搜索、日期分隔与发送状态、
  重新发送、会话信息、置顶消息条、已解散群、Enter 发送）、`npm run build`、`npm run check:api` 都通过。
- 本机浏览器（Vite + 模拟接口，Playwright）：1440×900 三栏（亮 / 暗）、1024×768 信息栏覆盖、390×844 会话列表 / 聊天 / 群信息 / 菜单 / 通讯录，
  都没有横向滚动与页面错误；手机上系统返回键按“信息 → 聊天 → 列表”逐层返回。
- `tests/e2e/sprint6_browser.cjs`（真实后端 + 真实 OpenIM，CI 的 ci-infra 任务）按新页面更新：通讯录从菜单打开、导出在“更多”里、
  群设置改为群信息栏，并检查消息页不显示工作台侧栏。
