> 后续变更（T-0149）：本文记录的自动化页面已随 n8n 移除；相关截图与扫描结果仅保留为当时的 UI 验证，当前页面范围见 `docs/architecture.md`。

## 1. 背景

界面审查（亮 / 暗 / 390px 截图）发现的外框问题：

| 问题 | 现象 |
|---|---|
| 顶栏拥挤 | 9 个文字按钮（搜索、创建、消息、待审批、通知全文、AI 助手、工作空间、用户名、主题、登出），手机上折成 3 行 |
| 侧栏没有图标 | 15 个入口只有同样的小方块占位，“管理”类入口和日常入口一样显眼 |
| 页头太高 | 工作空间名（与顶栏重复）+ 大标题 + 说明，约 200px |
| 时间格式 | `toLocaleString()`：浏览器语言决定格式，常见“10/30/2026, 2:05:09 PM”，带秒 |

UI 优化分四批，每批一个任务：本批（T-0083）只改外框；
第 2 批任务与项目（勾选完成、快速添加、今天 / 逾期视图、看板拖动、项目进度），
第 3 批首页与日历月视图，第 4 批手机底部导航与无障碍复查。

## 2. 决定

1. **图标库 `@lucide/vue` 1.60.0**（ISC 许可，`package.json` 精确版本）。
   - 来源：npm 仓库 <https://www.npmjs.com/package/@lucide/vue>，源码 <https://github.com/lucide-icons/lucide>；
     1.60.0 发布于 2026-10-20，只依赖 `vue >= 3.0.1`，没有其他运行时依赖。
   - 没有用 `lucide-vue-next`：npm 上整个包已标记弃用（“Package deprecated. Please use @lucide/vue instead.”）。
   - 按名字导入（`import { Bell } from '@lucide/vue'`），构建时只打包用到的图标。所有图标 `aria-hidden`，按钮的名字由文字或 `aria-label` 给出。
2. **设计令牌**：沿用原来的变量名（`--bg`、`--surface`、`--text`、`--muted`、`--line`、`--accent`…），
   新增 `--surface-2`（悬停底色）、`--accent-text`、`--success` / `--warning`（含 `-soft`）、`--radius-*`、`--sidebar-width`、`--topbar-height`，亮暗两套。
   正文字号与原来一致；`h1` 从 1.85rem 降到 1.45rem，页头说明行 0.86rem。
3. **侧栏**：品牌 → 工作空间（多个时是下拉框，名字仍是“当前工作空间”）→ 分组导航 → 账户。
   - 每个入口一个图标（`navIcons.ts`）。
   - 分组标题是按钮（`aria-expanded` / `aria-controls`），可以折叠；状态记在浏览器 `localStorage` 的 `workspace-nav-collapsed`，
     第一次只折叠“管理”。打开某一页时自动展开它所在的分组。存储不可用时只在内存里记住。
   - 底部账户区：头像（显示名首字）、显示名、中文角色；点开是“个人设置 / 安全设置 / 登出”菜单（reka-ui DropdownMenu）。
     主题切换是旁边的图标按钮；未登录时（登录页）主题按钮在顶栏。
   - 手机上侧栏仍然是“切换导航”打开的侧滑面板，入口最小高度 40px。
4. **顶栏**：左边是“分组 / 页面名”，右边是搜索框（宽屏显示“搜索”和 `Ctrl K`）、创建（主色按钮）、消息、待审批、通知、AI 助手。
   - 消息、待审批、通知改成图标 + 数字角标；可访问名称保持不变（“消息，N 条未读”“N 项待审批”“通知，N 条未读”“AI 助手 / 收起 AI 助手”“创建”），
     现有测试和读屏用法不受影响。
   - 手机上只显示图标，文字用视觉隐藏保留给读屏软件；顶栏保持一行。
   - 顶栏 `position: sticky`（滚动时留在顶部）。sticky 会形成层叠上下文，顶栏里的搜索框和通知中心是 `position: fixed` 的弹窗，
     所以用 `<Teleport to="body">` 挂到 body 下，否则会被限制在顶栏的层级里（改动前的浏览器测试 `browser-sprint5.cjs` 发现了这个问题）。
5. **页面主体**：去掉每页顶部重复的工作空间名（`.eyebrow`），工作空间名只在侧栏显示；主体内边距 28px / 32px（手机 20px / 16px）。
6. **时间格式**：`formatTime()` 统一为中文 24 小时制到分钟（`Intl.DateTimeFormat('zh-CN')`，例 `2026/11/02 14:05`），
   用浏览器所在时区；精确时间仍在 `<time datetime>` 里。日历已经按浏览器时区显示（`features/calendar/time.ts`），不变。

## 4. 第 2 批：任务与项目（T-0084）

只改前端，接口与数据表不变。

1. **智能视图**：全部 / 未完成 / 今天 / 已逾期 / 未来 7 天 / 已完成，转成列表接口已有的参数
   （`status`；`due_after` 含、`due_before` 不含），按浏览器时区在点选时计算（`features/tasks/shared.ts` 的 `viewQuery`）：
   今天 = 今天 0 点到明天 0 点的未完成任务；已逾期 = 截止早于现在的未完成任务；未来 7 天 = 现在到 7 天后的未完成任务。
   默认仍是“全部”。“更多筛选”（状态、项目、优先级、截止范围、标题）收进可展开区域，有生效的条件时自动展开；
   在那里填了截止范围时视图记为自定义。新增排序（截止时间 / 优先级 / 最近更新，接口已有的 `sort`）。
2. **快速添加**：标题 + 项目，回车保存；“今天”视图里添加的截止到今天 23:59。**勾选完成**：列表与看板卡片上的勾选框。
   两者都走原来的任务写入（`stores/taskOperations.ts`：Idempotency-Key、一次一个操作、结果未知时查询原请求）；
   成功后清掉结果面板，把接口返回的新版本写进列表缓存（连续勾选不会拿旧版本冲突），再后台刷新；失败时勾选框恢复原状，结果面板照常提示。
   结果未知时快速添加的标题保留，便于查询原请求。读屏通过隐藏的 `role="status"` 播报“已完成：…”“已添加任务：…”。
3. **看板拖动**：卡片拖到另一列即改变完成状态（HTML5 拖放）；拖到原来的列不发请求；勾选框是键盘与触屏可用的同等操作。
4. **任务行**：勾选框、标题、项目与标签、优先级、截止时间；未完成且已过期的标“逾期”（红），今天截止的高亮；
   日期写“今天 / 明天 / 昨天 + 时刻”，同一年省略年份。viewer 没有勾选框、快速添加与拖动，行内显示“已完成 / 未完成”。
5. **项目页**：卡片网格；每个项目一条完成进度条（已完成 / 全部，`role="progressbar"`）。项目颜色需要新字段，不在本批。

## 5. 第 3 批：首页与日历（T-0085）

只改前端，接口不变。

1. **首页标题**下是问候语与今天的日期（按浏览器时间，如“上午好，小明。今天是 11月3日星期二。”）。
2. **首页工具栏**：刷新（图标，名称仍是“刷新首页”）、添加组件、编辑布局常驻；导出 JSON、导入 JSON、选择仪表盘、设为首页
   收进“更多仪表盘操作”菜单（viewer 只有导出与选择）。选中后会打开对话框的项，先阻止 reka-ui 把焦点还给触发按钮，
   下一轮再打开对话框，焦点留在对话框里（与顶栏“创建”菜单同样处理）。
3. **任务组件**的“重试组件”：总览接口里模块正常时 `retryable` 也是 true，以前因此一直显示；改为只在出错或数据过期时显示。
   今日任务可点开任务抽屉（`/tasks?task=`），显示项目与截止时间（逾期标红，与任务页一致）；任务组件底部加“查看任务”链接。
   首页的项目进度条改用与项目页一致的样式。
4. **日历月视图**：6 周网格，从当月 1 日所在那周的周一开始；每格最多显示 3 项（日程按开始时刻，任务截止为黄色、只读、链接到任务），
   多出的显示“还有 N 项”；标出今天与不在当月的日子；上个月 / 下个月；点日期切到那一周的周视图。读取范围是 42 天加前后各两天的
   时区余量，在日历接口 92 天的上限内。手机上每格只显示圆点（文字仍保留给读屏）。

## 6. 第 4 批：手机与无障碍（T-0086）

只改前端，接口不变。

1. **手机底部导航**（≤760px）：总览、任务、项目、日历，第五项 owner / admin 是消息（未读数角标，名称“消息，N 条未读”），
   其他角色是知识库（与侧栏、路由守卫一致）；当前页 `aria-current="page"`；适配底部安全区（`viewport-fit=cover` + `env(safe-area-inset-bottom)`），
   打开的侧栏停在底部导航上方。是否显示用 `useMediaQuery('(min-width: 761px)')` 取反：没有 matchMedia 的环境（jsdom）按桌面处理，
   现有测试不受影响。
2. **触控尺寸**（手机）：顶栏图标 40px，视图切换与筛选标签 36px 高，勾选框 22px，按钮至少 40px，日历日期 32px，账户区 44px。
3. **无障碍复查**：用 axe-core 4.11.4（只装在本地临时目录，不进项目依赖）按 WCAG 2.0 / 2.1 / 2.2 A、AA 与 best-practice
   扫描总览、任务、项目、日历（周 / 月）、知识库、设置、安全设置、登录页（亮 / 暗 / 390px），以及开发者、运维、自动化、AI 审批、
   OpenClaw 实例、集成设置、密钥库、审计日志、消息（亮 / 暗）。发现并修掉的问题都在第 3 批的月视图：
   - `section` 上不能用 `role="grid"`，而且 grid 需要方向键导航：改成表格语义（`role="table"` / `row` / `columnheader` / `cell`），格子里的按钮与链接按 Tab 访问；
   - 不在当月的日期对比度 2.88:1：去掉半透明，改用正常的次要文字颜色；
   - 手机上 6px 的圆点是可点的目标：改成不可点的装饰圆点（`aria-hidden`），点日期进入那一周。
   修完后上述页面 0 个问题。键盘检查：从顶部连续按 Tab，侧栏、顶栏、视图切换、快速添加、任务行都能到达且焦点可见
   （快速添加框改为整个框显示焦点环）。减少动效偏好改为全局关闭过渡与动画。
