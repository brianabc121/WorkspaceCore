## Global Constraints

- Node 22 + npm ci; only apps/web and own task state/log; do not edit generated schema.d.ts, backend or Claude's acceptance paths.
- All queries include captured user/workspace; pages and dialogs remount on scope changes, late results never appear in a new scope.
- Tokens are password inputs, never initialized from responses or stored in browser storage, and cleared after submission.
- GitHub uses fixed service URLs, 1–20 deduplicated owner/repo entries and fine-grained github_pat_ tokens; admin-only writes.
- rate_limited and unauthorized are distinct from empty results; preserve marked stale projections on transient outages, hide inaccessible cached rows.
- Search is BFF metadata only; no AFFiNE content / Actions logs / GitHub writes / new third-party API assumptions.
- Reuse current responsive theme and safety checks for external links. One separate PR; Claude reviews/merges it.

## Review Focus

- A late search or integration write from an old workspace cannot expose results, notices or credentials in a new workspace.
- A rate-limited list with no cached rows must never present a normal empty state; retry_at stays visible even when overview differs from list sync.
- Partial repository permission failures must identify each repository, all four checks and actionable codes without revealing tokens.
- Keyboard navigation must use the same grouped order as rendered search results, including pages loaded later and safe external links.
- Write denial, version conflicts, unknown responses and successful writes followed by refresh failure must not permit duplicate writes or retain inaccessible editors.
