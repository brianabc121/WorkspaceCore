原生单执行者实施；一次新的独立上下文只读审查整个暂存 diff，对照任务、计划、OpenAPI 和实际后端。无 Critical、无单列 Minor。三个 Important 在同一修正轮次处理，未重复派审查：

1. **权限拒绝跨查询丢失**：搜索 store 按 user/workspace 保留拒绝状态并清除组件快照；过滤、查询与弹窗重开均不会恢复旧内容。只有新发起且匹配当前作用域和拒绝版本的成功读取可以解除。旧读取不能清除较新的拒绝状态。

## 实现选择 / 验证范围

- 沿用 Vue 3、TypeScript、Vue Query、vee-validate / Zod、现有弹窗与主题，不增加依赖。

- 浏览器覆盖创建 GitHub 连接、逐仓库权限检查、四种投影、故障摘要、限流空数据与重新连接、首页组件、BFF 搜索和连续日历导航、390px 无横向溢出、亮暗主题。全部为合成数据；无直接外部 API 请求或页面错误。
