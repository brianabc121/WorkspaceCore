- `/operations`：服务各状态、固定原因文案、最近检查时间；预设时间范围与视图；SVG 趋势和可访问数据表；可选安全 Grafana 外链。

- 查询和权限拒绝按用户 / 工作空间隔离；任一运维读取收到 403/404 时，共享拒绝状态隐藏两组件及页面缓存和链接。旧请求成功、配置变更不解除拒绝；主动验证两个端点后恢复。
- 区分首次错误、空数据、未部署、暂不可用、未授权和过期缓存。刷新失败保留原成功时间；首页概览失败不遮盖指标自己的未部署 / 不可用状态。
- 只读 BFF 请求，不生成 PromQL，不调用监控 API，不内嵌 Grafana。viewer 无写操作。无后端、迁移、生成类型或新依赖变更。
